# Prime Physique 💪

AI-based fitness coach (MVP)

## Features
- Personalized training plan
- Static & dynamic training week
- PDF export
- Expo (React Native) frontend
- Rust backend (Axum)

## Run backend
```bash
cd backend
cargo run
```

## 📱 PrimePhysique – App Vision

PrimePhysique is an AI-based fitness app focused on helping users
build muscle, stay consistent, and track real progress.

### 🔥 Core Features (MVP)
- Personalized training plans
- Weekly workout structure
- Progress tracking
- Clean and simple mobile UI

### 🚀 Future Features
- User accounts & authentication
- Nutrition tracking
- AI-based coaching
- Progress photos
- Push notifications
